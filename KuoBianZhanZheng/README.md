# 扩编战争（微信小游戏）

## 游戏介绍

《扩编战争》是一款竖屏单机微信小游戏。拖动部队自动战斗，招募新兵并三合一扩编，从班一路打到方面军，攻下 50 个敌军基地。单手可玩，无需联网。

## 玩法

- 拖动屏幕移动部队，小兵自动攻击射程内最近的敌人。
- 消耗军功招募班、排、连、营、团、旅、师、军、军团、方面军 10 级编制。
- 3 个同等级我方单位自动合体，兵力相加，可连锁升级；敌方不会合体。
- 击败敌方编制获得金币，可购买限时机枪、手雷、迫击炮，或兑换军功。
- 每关攻入上半屏随机生成的敌军基地，清空全部守军过关；我方兵力归零则失败。
- 共 50 关，每关开场自动保存快照，战败后可回到本关初始状态重试。

## 特色

- 敌军基地的房间、走廊、大门、墙体每局随机生成；短屏在部建筑较多时切换为四列。
- 墙体阻挡移动、子弹和视线；草丛可隐蔽，敌人不能进入草丛。
- 机枪每 0.2 秒扫射攻击圈内所有敌人；手雷每 0.5 秒投掷一颗。
- 两首原创 BGM，可分别开关背景音乐和战斗音效。
- 主菜单包含新的开始、继续游戏、设置、关于。
- 单机本地存档，无需服务器、无内购、无广告。

## 军功兑换

兑换按钮位于班至军的编制卡上方：1 金币 = 100 军功、5 金币 = 510、10 金币 = 1100、50 金币 = 5500、100 金币 = 12000。

手雷右侧依次为军团、方面军，攻击伤害分别为 6,561、19,683 兵力。新增两级敌军的金币击杀奖励沿用军级，每个单位 2 金币。

## 运行

- 浏览器预览：`node dev/serve.js 8124`，打开 <http://localhost:8124/dev/index.html>。
- 微信开发者工具：导入 `dist/CommanderSim`，项目类型选「小游戏」，填入小游戏 AppID 后编译。
- 上传/发布需要真实的小游戏 AppID；本地预览可用测试号。

## 存档

- `commanderSim.save.v1`：最高分、最高关卡、累计击杀、音乐/音效开关。
- `commanderSim.campaign.v1`：当前战役进度。
- `commanderSim.checkpoint.v1`：本关开场快照，战败重试时恢复。

## 敌方特殊武器

| 关卡 | 开场按当前兵力从高到低分配 |
| --- | --- |
| 1～19 | 全部使用普通步枪 |
| 20～29 | 第 1 名使用机枪 |
| 30～39 | 第 1 名使用手雷，第 2 名使用机枪 |
| 40～50 | 第 1 名使用迫击炮，第 2 名使用手雷，第 3 名使用机枪 |

- 一名敌人只持有一种特殊武器；持有者存活期间不因受伤或增援重新排名换装。
- 持有者死亡后，该武器自动交给当前存活且未持有特殊武器的敌人中剩余兵力最多者；兵力相同时按场上顺序选择。
- 场上人数不足时空缺保留，增援出现后补发。未出场的储备兵不参与排名。
- 敌方武器持续装备到死亡，不消耗我方金币，也不使用我方的 10 秒购买时限。
- 机枪：基础伤害 ×1，每 0.2 秒扫射一轮，命中射程内未隐蔽且有视线的所有我方单位。
- 手雷：基础伤害 ×2，每 0.5 秒一颗，爆炸半径 65。
- 迫击炮：基础伤害 ×3，每 1 秒一发，爆炸半径 100；沿用当前项目配置。
- 敌方保持原来的索敌射程、基地激活和草丛搜索规则；爆炸按落点范围伤害我方，不伤敌方同伴。
- 敌人下方显示武器名称，敌方曳光弹与爆炸弹体采用红色标记。
