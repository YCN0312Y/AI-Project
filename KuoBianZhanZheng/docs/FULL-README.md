# 扩编战争（微信小游戏）

## 游戏介绍

《扩编战争》是一款竖屏单机微信小游戏。拖动部队自动战斗，招募新兵并三合一扩编，从班一路打到方面军，攻下 50 个敌军基地。单手可玩，无需联网。

**特点**

- 原生微信小游戏 API，无引擎、无构建步骤、无图片资源（全部矢量绘制）
- **50 关逐关推进**，关卡编制表完全按需求设计；通关后进入下一关，部队、军功、金币和得分都会保留
- 10 级编制：班 / 排 / 连 / 营 / 团 / 旅 / 师 / 军 / 军团 / 方面军，兵力按 3 倍递增
- 半图敌军基地地图：基地占整个场景的一半，内部通道、各部建筑的位置与尺寸每局随机；下半图是玩家进攻区
- 敌军按编制住在「班部 / 排部 / 连部 / 营部 / 团部 / 旅部 / 师部 / 军部」里，玩家进入基地后分批放出
- 顶部实时显示关卡 N/50、敌军剩余部数/总部数、剩余兵力和场上数量
- 主菜单按钮从上到下为「新的开始」「继续游戏 · 第N关」「设置」「关于」；继续游戏会恢复到保存的关卡
- 「设置」按钮与「新的开始」同尺寸，位于「关于」上方，可分别开启/关闭背景音乐和战斗音效；设置自动保存
- 「关于」按钮在设置下方，与设置同尺寸；点开后显示制作人、AI 制作说明和反馈邮箱
- 两首程序化生成的原创循环 BGM：主菜单「紧张战场」、战斗「热血军事进行曲」（150 BPM）
- 底部可点击的征召面板 + 实时总兵力 + 军功/金币经济
- 随机泥土地面战场 + 手持步枪的小兵；单机玩法 + 本地存档（最高分、最高关卡、最高兵力、累计击杀、出征次数、当前战役进度）
- 触摸拖动操作，适配 DPR 与刘海安全区
- 包含暂停、胜利/战败结算、下一关、分享战绩

## 玩法

- **拖动屏幕任意位置**移动部队（相对拖动，手指不会挡住小兵）
- 玩家从下半图底部的「入口」出发，目标是攻入上半图的敌军基地
- **我方小兵为红色，敌方为白色**，方便快速区分
- **我方每个编制单位一次攻击射程内最近的一个敌人**；敌方编制单位也远程攻击单个目标，敌我双方都使用远程武器
- **伤害按等级固定**：1 级 1 人，之后每级 ×3（1 / 3 / 9 / 27 / 81 / 243 / 729 / 2187 / 6561 / 19683）
- **我方场上出现 3 个同等级编制时自动合体**成 1 个下一等级编制，兵力为三者当前兵力之和（例如 班5 + 班2 + 班11 → 排18）
- 战场有红褐色砖墙和部建筑，阻挡移动、子弹和视线；每栋部建筑内侧都接近整面开放
- 随机分布草丛：草丛可藏身；被敌人锁定后进草丛，敌人会失去目标并搜索 10 秒
- **整个战场是随机生成的泥土地面**：土色斑驳、车辙、碎石、干草，小兵手持步枪，攻击时枪口会转向目标，发射子弹曳光
- **战斗音效**：步枪/机枪射击、敌人射击、命中敌人、自己被击中、手雷爆炸
- 每局会随机分布草丛；进入草丛会隐蔽，敌人丢失锁定并搜索 10 秒
- **击败敌方编制单位会按编制等级获得金币**（班 0.1、排 0.25 …… 军 2），可在底部武器栏兑换机枪和手雷
- **点击底部 10 个编制卡**，消耗军功招募对应规模的编制单位（初始军功 300，第一关额外免费 1 个班）
- **敌军按关卡表分布在班部/排部/连部……军部里**，每关数量见下方关卡表
- 每栋部建筑开局有 **1 个对应编制的单位**站在屋内，其余为驻军储备；玩家进入基地后，各部开始分批放出援军，场上最多同时存在 24 个敌人
- **清空本关全部敌军单位 → 本关完成**，可以点击「进入第 N+1 关」
- 过关后保留部队、军功、金币和得分，并回复 25% 兵力；第 50 关通关后显示全部关卡完成
- 战败后可以「重试第 N 关」，**恢复到刚进入这一关时的军功、金币、当前编制及各编制兵力**（本关开场快照），而不是失败时已经打残的状态；从主菜单「新的开始」才会清空进度
- 军功来源：
  - **每消灭 10 点敌方兵力获得 1 军功**（不足 10 点累计到下一次：班 12 → +1、排 36 → +3、连 108 → +10、师 8,748 → +874……）
  - **战斗中每 3 秒自动获得 10 军功**（暂停/切后台不计时）
  - 拾取补给箱（+40 军功，并回复 20% 兵力）
  - 五档金币兑换：1→100、5→510、10→1100、50→5500、100→12000（金币→军功）
- **当前总兵力 = 场上所有编制单位的剩余人数之和**，显示在顶部 HUD
- 总兵力归零 → 全军覆没
- 场上最多同时存在 **20 个编制单位**；编制已满时底部会提示，损失后可继续招募
- **游戏会自动保存当前关卡**，包括该关卡的我方编制/兵力、军功、金币、得分和击杀数
- 重新打开游戏后，主菜单出现「继续游戏 · 第N关」；点击会以保存的部队重新开始这一关（敌军基地重新生成）
- **「新的开始」会清空战役进度**，从第 1 关重新开始
- **主菜单的「设置」**：可以分别开启/关闭「背景音乐」和「战斗音效」；选择会保存在本地，下一次启动继续生效
- **主菜单的「关于」**：设置在设置按钮下方，点击后弹出：
  - 制作人：渝常念
  - 游戏版本：V1.1
  - 纯AI制作，不喜勿喷！
  - 反馈/建议请发邮箱：ycn2182651251@gmail.com
- 背景音乐：主菜单播放「紧张战场」，进入战斗自动切换到 150 BPM 的「热血军事进行曲」；暂停、切后台时暂停，恢复后继续
- 战斗音效：玩家/敌人射击、命中、受伤、爆炸；与背景音乐使用**两个独立开关**

**得分** = 击杀分。通关或战败时写入最高分、最高兵力。

## 关卡系统（1~50 关）

### 编制表的含义

- 表里的数字是**部 / 编制单位数量**，不是兵力。
- **班部 1 = 1 个班 = 12 兵力**；**排部 1 = 1 个排 = 36 兵力**；连部 1 = 108 兵力；营部 1 = 324；团部 1 = 972；旅部 1 = 2,916；师部 1 = 8,748；军部 1 = 26,244。
- 例如第 3 关：3 个班部 + 1 个排部 = 3 个班 + 1 个排 = **4 个敌方单位 / 72 兵力**，不会把 12 兵力生成成 12 个班。
- 每关的每一类部建筑只建一栋，建筑上标注「班部 ×3」「排部 ×1」这样的部名和部数；屋内先出现 1 个单位，其余为储备，进入基地后分批放出。

### 战场与基地

- 敌军基地占整个游戏场景的一半；下半图是玩家进攻区（底部入口、2 个巡逻区）
- 基地内部布局每局随机：基地大门位置、中央通道宽度、部建筑在左右两列的分配、堆叠顺序、宽高和离通道距离都会变化
- 房间外墙间距和上下行间距更大，建筑不会挤成一整块
- 内侧门不一定保留：部分房间保留朝中央通道的内侧大开口，部分只开上/下方向，部分同时开多个方向，不再是清一色朝左/朝右的 U 型
- 援军会从房间实际存在的一个门口出现，不会生成在缺失的墙里面
- 玩家进入基地后，屋内驻军一起出击；各部每 0.5 秒放出最多 3 个单位，场上最多同时 24 个敌人
- 顶部 HUD：`关卡 N/50`、总兵力、得分；下方显示 **敌军 剩余部数/总部数 · 兵力 剩余总兵力 · 场上数量**
- 清空本关全部敌方单位后显示 **第 N 关完成**；如果有下一关，主按钮是 **进入第 N+1 关**
- 第 50 关完成后显示 **全部关卡完成**；战败后会恢复到本关开场状态再重试，主菜单可「新的开始」

规则：`兵力 = 12 × 3^(等级-1)`，招募消耗默认按「1 人 = 1 军功」。

### 战场上的“编制单位”

26,244 人不可能逐个画成小兵，所以每个编制单位在战场上只显示 **一个小兵 + 上方“等级 人数”标签**：

- 点击「连」→ 场上出现 1 个带 `连 108` 标签的单位
- 点击「军」→ 场上出现 1 个带 `军 2.6万` 标签的单位（总兵力仍按 26,244 计算）
- 单位受伤时标签人数实时下降，总兵力同步减少
- 单位人数归零则从战场消失

**敌方也使用同一套编制**：

- 我方标签是暗红底 + 等级色条；敌方是深灰底 + 兵种色条
- 敌方单位同样会受伤、人数下降，并发射红色子弹攻击我方
- 关卡模式不启用波次；敌军单位和编制等级由 1~50 关关卡表直接决定
- 三种敌人（普通/快/重装）仍然保留，区别在于速度、射程、攻击间隔和分值

### 战斗结算

- **兵力就是单位的生命值**，没有单独的 HP；头顶标签的人数就是剩余兵力
- **每次攻击伤害按攻击方等级固定**：1 级 1 人，之后每级 ×3
  - 班 → 1
  - 排 → 3
  - 连 → 9
  - 营 → 27
  - 团 → 81
  - 旅 → 243
  - 师 → 729
  - 军 → 2187
  - 军团 → 6561
  - 方面军 → 19683
- 我方编制单位每次开火会攻击**射程内最近的一个敌人**（默认射程 235）
- 敌方编制单位向最近的单个我方单位发射红色子弹，伤害同样按敌方等级计算
- 单位的兵力降到 0 才会从战场消失，头顶标签和顶部总兵力实时更新

单位的 `power` 指数仍然保留，但只用于子弹视觉大小和敌人分值，不再参与血量/伤害计算。

### 合体

- **我方场上**出现 3 个同等级编制时，自动合体为 1 个下一等级的编制
- 新编制的兵力 = 三个编制**当前兵力之和**
  - 例：三个班，当前兵力分别 5、2、11 → 合成一个排，兵力为 18
- 支持连锁合体：三个班合成一个排后，如果场上又凑齐三个排，会自动再合成一个连
- 只有**玩家单位**可以合体，敌人不会合体
- 方面军（10 级）是最高等级，不能再继续合体
- 合体后单位的兵力上限 = 合体时的兵力总和，后续回血不会超过这个上限
- 合体不会改变总兵力，只会减少场上的 Actor 数量、提升编制等级和攻击伤害

### 金币与武器

- 击败一个敌方编制单位时按编制等级发金币：**班 0.1 / 排 0.25 / 连 0.5 / 营 0.75 / 团 1 / 旅 1.25 / 师 1.5 / 军 2**
- 金币内部按小数累计，但底部金币栏**只显示整数**（例如 1.5 金币显示为 1），零头由下方进度条表示；攒满整币时才弹出 `+1 金币` 飘字
- **兑换军功位于原编制卡上方**：1 金币 = 100 军功、5 金币 = 510、10 金币 = 1100、50 金币 = 5500、100 金币 = 12000；余额不足对应档位时置灰，点击不会扣款。
- 底部按钮依次为机枪、手雷、迫击炮、军团、方面军；顶部显示金币余额。
- 步枪：默认武器，没有换装的小兵都使用单发步枪
- 机枪：**3 金币**，装备给当前兵力最多的 Actor，持续 **10 秒**；期间**每 0.2 秒**扫射一轮，每轮同时攻击**攻击圈内所有有视线的敌人**，每个敌人受到一次机枪伤害
- 手雷：**5 金币**，装备给当前兵力最多的 Actor，持续 **10 秒**；期间**每 0.5 秒**自动投掷一颗手雷，10 秒后自动恢复步枪
- 点击当前已激活的武器按钮只会提示剩余秒数，不重复扣费
- 切换到另一种武器会重新扣费并重新计时，同时替换掉原来的武器
- 只有被选中的那个 Actor 使用限时武器，其他小兵仍然是步枪
- 如果当前武器手参与合体，武器模式和剩余时间会转移到合体后的单位上

### 掩体 / 砖墙 / 草丛

- 战场使用红褐色砖墙和各部建筑砖墙（位置每局随机），采用矩形碰撞
- 墙壁会阻挡玩家、敌人、子弹和视线；基地大门和每个班部大门都是大开口
- 每局会随机生成若干**草丛**：不阻挡玩家移动和子弹，玩家小兵走进去后会进入隐蔽状态（头顶显示「隐蔽」）
- **草丛对敌方单位是实心的**：敌人不能进入草丛，也不会和草丛图片重叠；敌方寻路会把草丛当成障碍绕开，玩家仍然可以进入躲藏
- **玩家大编制移动**：师、军等单位使用比视觉体型更小的移动碰撞体，并支持沿墙滑行；即使体型很大，也能通过房间之间的窄通道，视觉体型保持不变
- 草丛生成时会检查墙体的完整碰撞范围，**不会与砖墙重叠**；还会避开部屋门口和基地大门，避免敌人被草丛堵死
- 草丛掩体分两种美术：小草丛（`grass.png`）和灌木丛（`shrub.png`），随机混合生成，带轻微摇摆和镜像变化；没有图片时回退到程序化草叶
- 两种草丛都可以隐蔽，进入后敌人同样会丢失锁定并搜索 10 秒
- 隐蔽状态下：
  - 玩家进入的那个草丛会降低透明度，方便看到自己的部队
  - 敌人始终绘制在草丛之上，不会被草丛遮住
  - 敌人无法锁定草丛里的单位，已经锁定的也会丢失目标
  - 草里的我方单位会停火保持隐蔽，离开草丛后恢复攻击
  - 敌人丢失目标后会随机方向巡逻，每次短距离移动后短暂停顿并换向，不会一直朝同一个方向走；**10 秒内找不到玩家，就返回自己原来的驻守位置**
  - 如果玩家离开草丛被敌人重新看见，敌人会立即恢复攻击
- 玩家小兵可以从基地大门进入基地，再进入班部房间
- 屋内驻军在基地激活后从班部大门出击；后续援军也直接从班部门口出现
- 所有基地文字、部名、巡逻区、入口和编制标签都绘制在掩体和草丛之上，不会被遮挡
- 我方射击会检查视线，隔着墙不会命中
- 敌人使用细网格 BFS 流场寻路绕过墙壁和草丛：网格固定为 8px、掩体膨胀 6px，能识别门缝和房间之间的窄道；屋里驻军目标在屋外时会先走真实存在的门口，前方被墙挡住时沿墙搜索可行方向，不会顶着墙堆成一排
- 敌人的移动碰撞半径比绘制体积小，三级以上的大编制也能穿过窄门和房间间隙，减少互相卡死
- 补给箱不会刷在墙壁内部
- 代码中保留房屋/掩体系统；关卡模式不再生成石头，石头相关绘制/碰撞能力仅供其他地图模式使用

### 背景音乐与音效

- 主菜单底部有同尺寸「设置」和「关于」按钮；设置可分别开关「背景音乐」和「战斗音效」，关于显示制作人与反馈邮箱
- 主菜单使用指挥官头像图标；同一张图也可在微信公众平台作为小游戏头像上传
- 主菜单循环播放「紧张战场」；点击新的开始或继续游戏后自动切换到 150 BPM 的热血军事进行曲
- 「紧张战场」使用低频三全音/小二度、双重心跳和低音脉冲营造压迫感；已移除高音警报和持续高音，并做高频柔化，减少刺耳鸣声
- 两首 BGM 都是程序化生成的原创循环音频（16 秒无缝循环，WAV），不依赖外部版权素材；版本内已降低铜管高次谐波和高频镲片
- 战斗音效：枪声、敌人枪声、命中敌人、我方受伤、手雷爆炸；关闭「战斗音效」会同时静音玩家和敌人的攻击声及其他战斗音效
- 小兵攻击时，步枪枪口会旋转到当前攻击目标的角度
- 暂停、切后台时音乐暂停；恢复游戏时继续
- 浏览器预览有自动播放限制：首次点击页面（菜单或设置按钮）后才会出声；微信小游戏真机同样以用户首次交互为准
- 真机音频跟随手机媒体音量；代码已设置不跟随 iOS 静音拨片，并在首次触摸时预解锁音效。若仍无声，请检查手机媒体音量、游戏内「背景音乐/战斗音效」开关，以及手机上运行的是否为最新体验版
- 重新生成音频：`node tools/generate-bgm.js` 和 `node tools/generate-sfx.js`（输出到 `assets/audio/`）

## 浏览器快速预览（开发用）

小游戏代码不依赖 DOM，所以附带了一个 `wx` API 垫片，可以直接在浏览器里调玩法：

```bash
node dev/serve.js 8124
```

然后打开 <http://localhost:8124/dev/index.html>。

- `dev/` 目录只用于本地预览，**不会打包进小游戏**
- 浏览器里可以用 `__tap(x, y)` / `__drag(x1, y1, x2, y2)` 在控制台模拟触摸
- 页面里的 `globalThis.__commanderSim` 是游戏实例，方便调试
- 预览壳默认不模拟“切后台暂停”（标签页可见性在浏览器里会频繁变化）；需要测试时在控制台执行 `window.__enableAutoPause = true`

> 在微信开发者工具的 Console 里也可以访问 `globalThis.__commanderSim`。

## 调参与扩展

打开 `js/config.js`：

| 配置 | 含义 |
| --- | --- |
| `TROOP_TIERS` | 10 个等级的名称、兵力、招募消耗、**每次攻击伤害**、颜色 |
| `squad` | 编制单位移速/射程/攻速、子弹速度、回血、阵型间距、单位数量上限 |
| `merit` | 初始军功（300）、清波军功奖励、每 3 秒自动 +10 军功、每多少点敌方兵力换 1 军功（`troopsPerMerit`，默认 10） |
| `LEVELS` | 1~50 关的编制表：每关各班/排/连/营/团/旅/师/军/军团/方面军部的数量 |
| `level` | 每批援军数量、场上敌人上限、放兵间隔、过关回血比例（每部开局固定屋内 1 个单位） |
| `enemy.types` | 三种敌人的速度、射程、体积、分值、远程攻击间隔 |
| `enemy.tierEveryWaves` / `enemy.maxTier` | 敌方编制每几波升级一次、最高升到几级 |
| `enemy.searchTime` | 玩家进草丛后敌人的搜索时长（期间随机方向巡逻） |
| `enemy.flowCell` / `enemy.flowClearance` / `enemy.flowRefresh` | 敌人寻路网格大小、掩体膨胀距离与寻路场刷新间隔 |
| `enemy.arrowSpeed` | 敌方红色子弹的飞行速度 |
| `wave` | 第一波准备时间、波间准备时间、每波数量、数量倍率、出生间隔、成长曲线 |
| `crate` | 补给箱军功、回血比例、拾取范围、刷新数量、掉落概率 |
| `merge` | 合体所需数量（默认 3）、是否启用我方合体（敌方默认关闭） |
| `coins` | 各编制击败奖励金币（`rewards`）、五档军功兑换（`exchanges`） |
| `weapons` | 机枪/迫击炮/手雷的价格、持续时间、伤害、范围、攻击间隔 |
| `covers` | 小掩体/房屋数量、半径与房屋尺寸、出生区留空、掩体间距 |

关键公式（关卡模式不启用波次；以下 wave 参数留给未来的波次玩法）：

- 第 n 关班部数量：`n`；排部：`max(0, n-2)`；连部：`max(0, n-4)`；营部：`max(0, n-6)`；团部：`max(0, n-8)`；旅部：`max(0, n-10)`；师部：`max(0, n-12)`；军部：`max(0, n-14)`
- 第 n 关敌军单位数：各部数量之和
- 第 n 关总兵力：`班部×12 + 排部×36 + 连部×108 + 营部×324 + 团部×972 + 旅部×2916 + 师部×8748 + 军部×26244`
- 每关各部开局屋内 1 个单位，其余为储备；每 `0.5` 秒放出最多 `3` 个单位，场上最多同时 `24` 个敌人
- 每次攻击伤害：`1 × 3^(攻击方等级 - 1)`（即 1 / 3 / 9 / 27 / 81 / 243 / 729 / 2187）
- 视觉大小/敌人分值：`power = (兵力 / baseTroops) ^ powerExponent`（默认 0.5，只影响表现和分值）
- 招募消耗：`TROOP_TIERS[i].cost`（默认等于兵力）
- 击败金币：`coins.rewards[tier-1]`，默认班→军为 `0.1 / 0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2`
- 被动军功：战斗中每 `merit.passiveInterval = 3` 秒自动增加 `merit.passiveAmount = 10` 军功
- 击杀军功：按实际消灭的敌方兵力累计，`merit.troopsPerMerit = 10`，即每 10 点兵力 +1 军功；把数字改小会提高军功收入
- 金币换军功：`coins.exchanges` 定义五档兑换，按钮位于原编制卡上方。

关卡难度优先调：`LEVELS`（每关各编制数量）、`level.activeCap`（场上敌人上限）、`level.spawnBatch` / `spawnInterval`（援军速度和批量）、`level.healBetweenLevels`（过关回复）、`merit.start`（初始军功）。

配色在 `js/config.js` 的 `COLORS` 和 `TROOP_TIERS[].color` 里。

## 本地存档

`js/storage.js` 使用 `wx.setStorageSync` / `wx.getStorageSync` 保存：

```js
{
  bestScore,   // 最高分
  bestWave,    // 最远关卡
  bestTroops,  // 历史最高总兵力
  totalKills,  // 累计击杀
  plays,       // 出征次数
  musicOn,     // 背景音乐开关（默认 true）
  sfxOn        // 战斗音效开关（默认 true）
}
```

存储 key 是 `commanderSim.save.v1`。

战役进度另存于 `commanderSim.campaign.v1`：

```js
{
  level,        // 当前保存的关卡
  army,         // [{ tier, troops, troopsMax, slot }]
  merit,        // 军功
  meritProgress,// 距离下 1 军功还差多少敌方兵力（0~9）
  coins,        // 金币（可带小数）
  score,        // 得分
  kills,        // 击杀数
  peakTroops    // 本战役最高兵力
}
```

- 关卡开始、过关、切后台、返回主菜单时会自动保存当前战役进度
- 「继续游戏」会用保存的部队重新开始保存的关卡，敌军和基地会重新生成
- 「新的开始」会清空战役进度并从第 1 关重新开始
- 清理微信缓存或换设备会丢失本地进度，不会同步到服务器

**本关开场快照**另存于 `commanderSim.checkpoint.v1`，结构与上面的战役进度相同：

```js
{
  level,        // 快照对应的关卡
  army,         // 进入本关时的我方编制及各自兵力
  merit,        // 进入本关时的军功
  meritProgress,// 军功零头进度
  coins,        // 进入本关时的金币
  score,        // 进入本关时的得分
  kills,        // 进入本关时的击杀数
  peakTroops    // 进入本关时的最高兵力
}
```

- 第 1 关开始、以及每次进入下一关时写入快照（下一关会先结算 25% 回血，再记录）
- 本关失败后点「重试第 N 关」，会恢复这份快照：军功、金币、编制、各编制兵力、得分和击杀数都回到刚进本关时
- 本关中途切后台、返回主菜单后再「继续游戏」，恢复的是当前进度；但失败重试仍然回到本关开场快照
- 「新的开始」会同时清空战役进度和本关开场快照

## 敌方特殊武器

| 关卡 | 开场按当前兵力从高到低分配 |
| --- | --- |
| 1～19 | 全部使用普通步枪 |
| 20～29 | 第 1 名使用机枪 |
| 30～39 | 第 1 名使用手雷，第 2 名使用机枪 |
| 40～50 | 第 1 名使用迫击炮，第 2 名使用手雷，第 3 名使用机枪 |

- 一名敌人只持有一种特殊武器；持有者存活期间不因受伤或增援重新排名换装。
- 持有者死亡后，该武器自动交给当前存活且未持有特殊武器的敌人中剩余兵力最多者；兵力相同时按场上顺序选择。
- 场上人数不足时空缺保留，增援出现后补发。未出场的储备兵不参与排名。
- 敌方武器持续装备到死亡，不消耗我方金币，也不使用我方的 10 秒购买时限。
- 机枪：基础伤害 ×1，每 0.2 秒扫射一轮，命中射程内未隐蔽且有视线的所有我方单位。
- 手雷：基础伤害 ×2，每 0.5 秒一颗，爆炸半径 65。
- 迫击炮：基础伤害 ×3，每 1 秒一发，爆炸半径 100；沿用当前项目配置。
- 敌方保持原来的索敌射程、基地激活和草丛搜索规则；爆炸按落点范围伤害我方，不伤敌方同伴。
- 敌人下方显示武器名称，敌方曳光弹与爆炸弹体采用红色标记。
