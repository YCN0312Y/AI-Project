# 缅因猫抚摸模拟器 · Maine Coon

基于用户提供的缅因猫六视图生成摄影棚照片，保留棕黑虎斑、耳尖毛和蓬松尾巴，并用 WebGL2 网格驱动抚摸和翻身。

[手机和电脑浏览器在线游玩](https://ycn0312y.github.io/AI-Project/Cat/)

## 核心特性

- **极速满帧性能（< 0.5 ms 单帧渲染）**：
  - 移除逐像素重度多层噪声卷积，改用硬件双线性插值的物理形变照片网格 + `256×170` 轻量顺毛缓冲，画面按最高 `1.5x` 视网膜倍率输出，核显与移动端均可稳定跑满 60 / 120 FPS。
- **缅因猫的互动**：
  1. **翻身（`R` 键 / 按钮）**：猫咪先单爪撑地、转移重心，再收爪侧倒，最后仰躺露肚皮。翻回时先侧身，再撑地坐起。
  2. **打呼噜（`M` 键 / 按钮）**：双相呼吸包络 26 Hz 喉部呼噜共振与顺毛声，画面中的胸口随呼吸缓慢起伏。
  3. **喵喵叫（`C` 键 / 按钮 / 轻点鼻嘴）**：三共振峰声道滤波合成 4 种猫叫声与颤音，同步混合张嘴表情。
  4. **猫爪开花（`P` 键 / 按钮 / 轻点肉垫）**：四只肉垫猫爪独立交替踩奶、四趾与粉豆豆肉垫大幅扇形张开。
  5. **喂猫粮（`F` 键 / 按钮）**：猫咪坐稳后低头吃粮，食碗里的颗粒随咀嚼逐口减少，吃完后抬头回到端坐。
  6. **待机动作**。光标移出画面后，猫咪闲置约 8 秒会开始轮流舔前爪、翻滚和歪头。抚摸、喂食和 360° 查看时暂停待机动作。
- **360° 查看（`V` 键 / 左上角按钮）**：左右拖动画面、移动角度滑条或使用左右方向键，环绕查看端坐猫咪的八个照片视角及其过渡。点「回正」跳到正面，点「返回抚摸」或按 `Esc` 回到互动。
- **拟真抚摸物理**：
  - 揉脸、抬下巴、摸耳、甩尾和顺毛只在猫的图层内渲染。摄影棚背景固定，手部接触阴影只落在猫身上。

## 运行方式

1. 双击 `Source/index.html` 可离线打开，页面内置 Base64 贴图包。
2. 在项目根目录双击 `启动猫猫模拟器.cmd`，也可以执行 `node serve.cjs 8148` 后打开 `http://127.0.0.1:8148/`。

网页源码、样式和运行资源分别位于 `Source/js/`、`Source/css/` 和 `Source/assets/`。
