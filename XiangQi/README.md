# 中国象棋 (Chinese Chess / Xiangqi)

一个使用 Python + Pygame 实现的功能完整的中国象棋游戏。

## 功能

- ✅ **基础功能**：标准棋盘与 32 棋子绘制、所有棋子合法走法（车马象士将炮卒）、轮流走棋、胜负判定（将死/困毙/照面）
- ✅ **悔棋**：支持撤销上一步（含 AI 对战下的双方各一步）
- ✅ **提示**：高亮当前选中棋子的合法落点
- ✅ **AI 推荐走法**：点「提示」用比对手更强的搜索（深度 8 / 3.5 秒）在后台分析，棋盘上出现玉青色弧线箭头与起落点光环，河界处弹出一枚漆面建议卡：中文棋谱（如「炮八平五」）+ 分析深度 + 走后形势 + 对手最强回击预测；再点一次清除
- ✅ **吃子记录**：侧栏显示双方已吃棋子
- ✅ **终局回看**：分出胜负后弹出结果卡，点棋盘空白处（或「回看棋局」）即可收起卡片看到终局棋型；侧栏胶囊变「复盘 n/N」，用胶囊两侧的 ◀ ▶ 或键盘 `←` `→` 逐手回看，棋盘上同步显示该手的金色走子箭头与起落点高亮，侧栏给出中文棋谱与吃子提示（如「6. 炮8进1 吃马」）；再点棋盘空白处回到终局，再点一次回到结果卡
- ✅ **计时器**：每方 15 分钟倒计时，超时判负
- ✅ **人机对战**：迭代加深 Negamax + Alpha-Beta + 静态搜索 AI，三档难度（简单/正常/困难），开局菜单可选、对局中按 1/2/3 或点侧栏难度药丸随时切换；玩家执黑时棋盘自动翻转 180°，己方棋子始终在下方
- ✅ **暂停**：点击侧栏标题左侧的暂停按钮，或按 `P` / 空格冻结计时、AI 落子与棋盘操作；恢复后继续对局
- ✅ **存档/读档**：JSON 序列化与恢复（含当前难度）
- ✅ **音效与动画**：程序合成的木质落子声（三档随机变体）；吃子时叠加棋子互撞声与「打吃」人声；棋子平滑移动动画
- ✅ **背景音乐**：约 21 秒无缝循环的五声音阶拨弦小品（90 BPM，拨弦 + 低音 + 混响，程序实时生成）；在菜单、选边与难度界面播放，进入对战自动淡出停止；菜单右下角音符按钮或 `M` 键开关
- ✅ **界面美化**：紫檀木桌面、木纹棋盘与象牙棋子（4× 超采样抗锯齿）、漆器红标题栏、可悬停的木质按钮、可点击难度药丸；选中/上一步/走法提示/被将军均有独立高亮
- ❌ 网络对战（不在本次范围）

## 安装

```bash
pip install -r requirements.txt
```

## 运行

```bash
python Source/main.py
```

启动后选择：
- **双人对战**：本地双人轮流走棋
- **人机对战**：选择执红或执黑，与 AI 对弈（选黑时棋盘自动翻转，己方棋子始终在下方）
- **读取存档**：加载最近的存档继续游戏

Windows 也可双击项目根目录的 `play.bat` 或 `run.bat`。

## 操作

| 操作 | 方法 |
|---|---|
| 选择/落子 | 鼠标点击棋盘 |
| 悔棋 | 点击侧边栏「悔棋」按钮 |
| 显示所有合法走法 / 推荐下一步 | 点击「提示」按钮（再次点击清除） |
| 切换 AI 难度 | 点击侧栏「简单 / 正常 / 困难」药丸，或按 `1` / `2` / `3` |
| 暂停 / 继续 | 点击侧栏标题左侧的暂停按钮，或按 `P` / 空格；暂停时计时与 AI 都停止 |
| 存档 | 点击「存档」按钮（写入 `saves/` 目录） |
| 读档 | 点击「读档」按钮（加载最近存档） |
| 新对局 | 点击「新游戏」按钮 |
| 终局回看 | 结果卡弹出后点棋盘空白处或「回看棋局」收起卡片；侧栏胶囊两侧 ◀ ▶ 逐手复盘；点棋盘空白处回到终局 / 结果卡 |
| 切换 AI | 点击「切换 AI」按钮（双人 ↔ 人机，沿用当前难度） |
| 返回上一级 | 选边/难度界面点左上角「返回」，或按 `Esc` |
| 开关背景音乐 | 菜单右下角音符按钮，或按 `M`（对战界面不播放背景音乐） |
| 退出 | 点击「退出」按钮、按 `Esc` 或关闭窗口 |

## 规则说明

- 坐标系统：`(列, 行)`，列 0-8（左→右），行 0-9（红方底线 → 黑方底线）
- 河界在行 4-5 之间
- 九宫：双方各 `列 3-5 × 行 0-2`（红）/ `行 7-9`（黑）
- **将军判定**：将/帅被对方任何棋子攻击到
- **胜负判定**：将/帅被吃 → 立即胜负；将死 → 当前方判负；困毙 → 当前方判负
- **照面**：将帅不能在同一列上、中间无任何棋子

## AI 说明

- 搜索算法：迭代加深 Negamax + Alpha-Beta 剪枝，叶子节点接静态搜索（quiescence，只展开吃子/应将），走法排序用 MVV-LVA + killer + 历史启发表
- 难度档位（`ai.py: DIFFICULTY_SETTINGS`）：

  | 难度 | 名义深度 | 时间预算 | 静态搜索 | 随机窗口（开局/中局） |
  |---|---|---|---|---|
  | 简单 | 1 | 0.5 s | 不做 | 80 / 50 |
  | 普通 | 5 | 1.2 s | 2 层 | 25 / 8 |
  | 困难 | 6 | 2.5 s | 3 层 | 12 / 3 |

  实际深度由迭代加深在时间预算内决定（开局约 3-4 层、中局约 4-5 层）；完成不了的一层会被整体丢弃，绝不用“搜到一半”的分数做决策。随机窗口只在高分候选中随机挑选，档位越低越随意，高难度更接近最佳走法。
- 评估函数：子力价值 + 兵/马位置加成 + 被将军惩罚
- 时间保证：每步思考不超过该档时间预算（约为预算上限，而不是旧版的 1.5 秒固定上限）
- 线程安全：AI 在后台线程搜索“棋盘快照”，对局中悔棋/新游戏/读档/换难度会让旧结果作废，不会把过期走法落到新局面上
- 「提示」用独立的强档搜索：深度 8 / 3.5 秒 / 确定性选子，同一局面给出的建议稳定且不会比对手 AI 弱；分析在后台线程进行，河界建议卡会先显示「分析中」动画

## 快捷键

- `1` / `2` / `3`：切换 AI 难度（简单 / 普通 / 困难），对局中随时可用；难度选择菜单里也可直接按数字
- `P` / 空格：暂停或继续对局（计时与 AI 同步暂停）
- `←` / `→`：终局回看时逐手复盘；`Home` / `End` 跳到开局 / 终局
- `R` / `Enter`：终局回看时在结果卡与棋型之间切换
- `M`：在菜单、选边与难度界面开关背景音乐（对战界面不播放背景音乐）
- `Esc`：退出游戏

## 已知限制

- 不支持长将/长捉判负（保持规则简单）
- 不支持打谱导入
- 音效需要 numpy + 可用音频设备；不可用时自动静默
- AI 无置换表/开局库，长时间对局后期仍会明显慢于商业引擎
