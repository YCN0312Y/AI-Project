## 职务阈值改为 12 × 3^n 等比数列

- 用户给出规则：班长 12 兵力，排长 = 班长 ×3，之后每级 = 上一级 ×3；职务序列 排长/连长/营长/团长/旅长/师长/军长/军团长/司令员。
- 计算结果：12 / 36 / 108 / 324 / 972 / 2,916 / 8,748 / 26,244 / 78,732 / 236,196（共 10 级，总倍数 3⁹ = 19,683）。
- `js/state.js`：把上一版的 `RANK_STEPS`（120 排长起、每 20 兵力一级、含副职）整体替换为上述 10 级表。`rank()` / `rankIndex()` / `rankProgress()` 是通用的，不用改；`js/game.js` 面板文案也是通用的，不用改。
- **重要后果**：初始兵力 120 落在新表的「连长」档（108 ≤ 120 < 324），顶部从「排长 / 兵力 120」变为「连长 / 兵力 120」。这与用户 11-08 那次「120 给到排长」的要求相反，但用户看过冲突说明后明确要求「职位就根据刚统计的兵力来计算」，故按表落地。若以后要恢复 120=排长，可把表平移为 120/360/1,080…，或把初始兵力改 36。
- **未解决的设计问题**：商城「新兵征召」每次只 +20 兵力，指数门槛下从军团长升司令员需 7,874 次购买。用户未要求改，本次没动 `GOODS` / `purchase()`。
- `README.md` 同步规则说明；`tests/state.test.js` 第 8 个测试改为遍历 10 级阈值 + 验证 120=连长、军功不影响、封顶司令员、商城 +20 后仍是连长。
- 验证：`npm test` 8/8；CDP 无头 Chrome 1440x900 截图确认大厅「连长 / 兵力 120」、面板「现任职务 连长 / 兵力 120 · 再扩编 204 兵力晋升 营长 · 军功 0」，进度条约 5.6%，无溢出、无 JS 报错。

## 主界面背景音乐（军事进行曲）

- 项目原本没有任何音频资源，`preview/wx-shim.js` 也没有音频 API。
- `tools/make-music.py`（新增）：纯标准库合成 8 小节 D 小调进行曲（112 BPM，军鼓 / 低音鼓 / 铜管号角 / 低音 oom-pah / 镲 / 和弦垫），22050Hz 单声道 WAV → ffmpeg(libmp3lame) 转 `audio/march.mp3`（17.5s、207KB、96kbps）。重跑脚本即可重新生成。
- `js/music.js`（新增）：`src='audio/march.mp3'`、loop、volume 0.35；只在 lobby 播放，进战斗/切后台暂停；设置可开关。`unlockMusic()` 处理浏览器首次交互，`pumpMusic()` 每 500ms 兜底重试——**关键**：点击当次的 `play()` 会被拒、手势稍后才生效，只在 touch 里试一次会永远不响，这是实测踩过的坑。
- `preview/wx-shim.js`：补 `createInnerAudioContext()`（用 `HTMLAudioElement` 模拟微信 InnerAudioContext）+ `onShow`（原来只有 hide）。注意 `new Audio()` 创建的元素不在 DOM 里，`document.querySelectorAll('audio')` 查不到，验证要 hook `HTMLMediaElement.prototype.play`。
- `js/state.js`：`settings.music` 默认 true，`normalizeSave` 布尔白名单加 `music`。
- `js/game.js`：constructor 初始化并注册 onShow，touch 调 `unlockMusic`，tick 调 `pumpMusic`，start/home 切场景，设置面板加第三项开关（间距 115→100，底部文案 560/610→575/625）。
- `tools/serve.cjs`：补 `.mp3: audio/mpeg`（原来会返回 octet-stream）。`project.config.json` 的 packOptions.ignore 不含 audio/，音乐会被打进小游戏包。
- 验证：`npm test` 9/9；CDP 验证播放/循环/音量/开关/进战斗暂停/回大厅恢复；**单独用不带 autoplay 豁免参数的 Chrome** 验证「未交互 paused=true → 首次点击后 paused=false」；设置面板三项开关截图无重叠；无 JS 报错。
